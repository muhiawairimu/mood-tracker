# 🌟 Daily Mood & Habit Tracker

A lightweight, fully responsive Progressive Web App (PWA) designed to help you track daily moods, monitor habits, log journal reflections, and build long-term streaks.

---

## ✨ Features

- **Mood Tracking:** Log daily moods with intuitive emoji selections and view monthly trends on an interactive calendar.
- **Habit Checklist:** Add, complete, and manage daily habits with real-time completion progress bars.
- **Streak Tracker:** Automatically calculates multi-day habit streaks to keep you motivated.
- **Daily Reflection Journal:** Auto-saving note area for quick evening check-ins.
- **Offline & Installable (PWA):** Install directly onto iOS or Android home screens and use without an internet connection.
- **Dark / Light Mode:** Dynamic theme switching based on your preference.
- **Local Privacy:** All data is saved directly in your browser (`localStorage`) — no sign-ups or remote servers required.
